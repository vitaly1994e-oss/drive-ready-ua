# DRIVE READY 360° — навчальний модуль

Адреса: https://drive-ready-ua.onrender.com/ready360.html

Реалізовано у статичному сайті:
- Перевірені відкриті зображення схем ТСЦ (з існуючих каталогів) та вибір маршруту через URL `?center=6341&route=1`
- Паспорт помилок із категоріями маневрів, нотатками, необов'язковою ручною позначкою на зображенні, станом «відпрацьовано»
- Авторські інтерактивні навчальні питання з поясненнями
- План повторення за категоріями **власних** невідпрацьованих помилок
- JSON-експорт та імпорт після підтвердження, друк навчального звіту
- Локальна інтеграція з журналом інструктора та сторінкою прогресу

Не реалізовано:
- Геоприв'язані реальні «складні точки» та відео конкретних перехресть (їх потрібно перевіряти, а не вигадувати)
- Запис і аналіз реального водіння, GPS-моніторинг, автоматичне визначення помилок
- Хмарний вхід/синхронізація, спільний кабінет інструктора та учня з розмежуванням прав, server API
- Гарантований офлайн-доступ до сторонніх зображень схем

Дані зберігаються у браузері користувача за ключем `dru-ready360-v1`. Не обробляйте в ньому чутливі персональні дані. Ручні маркери означають **позначки користувача на зображенні**, а не перевірені географічні координати чи автоматичне визначення небезпечних місць. Вправи виконують **лише до або після керування**.

Тестування: `tests/browser.mjs` у GitHub Actions, основні перевірки `tests/validate.py`.
