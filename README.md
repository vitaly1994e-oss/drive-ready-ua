# DRIVE READY UA

Незалежна україномовна освітня платформа: https://drive-ready-ua.onrender.com/

## Безкоштовна підготовка до іспиту з водіння в Україні

**[DRIVE READY UA — почати навчання](https://drive-ready-ua.onrender.com/)**

Без оплати та підписки: [тести ПДР](https://drive-ready-ua.onrender.com/quiz.html), [практичні ситуації](https://drive-ready-ua.onrender.com/practice.html), [пробний іспит](https://drive-ready-ua.onrender.com/coach.html), [чекліст](https://drive-ready-ua.onrender.com/exam-checklist.html), [маршрути практичного іспиту МВС](https://drive-ready-ua.onrender.com/routes.html).

Каталог охоплює 73 записи територіальних сервісних центрів і **22 сторінки областей/Києва** з перевіреними схемами частини маршрутів. Схеми публікуються в контексті навчання, з позначенням джерела. Вони не гарантують прийом іспиту в конкретному ТСЦ.

**Популярні регіони:** [Харків](https://drive-ready-ua.onrender.com/regions/kharkiv.html) · [Київ](https://drive-ready-ua.onrender.com/regions/kyiv-city.html) · [Київська область](https://drive-ready-ua.onrender.com/regions/kyiv-oblast.html) · [Одеса](https://drive-ready-ua.onrender.com/regions/odesa.html) · [Львів](https://drive-ready-ua.onrender.com/regions/lviv.html) · [Дніпро](https://drive-ready-ua.onrender.com/regions/dnipro.html).

Маєш посилання на нові офіційні схеми? Відкрий issue з номером ТСЦ і джерелом, щоб ми могли перевірити та додати їх без вигадування геометрії.

## Що реально працює
- Адаптивна головна сторінка, темна/світла тема та мобільне меню
- Пошук серед понад 70 записів ТСЦ МВС за областю, містом, номером
- Відображення частини офіційних схем маршрутів з сайту ГСЦ МВС (станом на листопад 2026; перед іспитом перевіряти актуальність)
- Авторські теоретичні запитання, імітація формату 20 запитань / 20 хвилин
- Практичні ситуації й озвучення українською, якщо браузер має український голос
- Збереження прогресу в localStorage, друк чекліста, експорт прогресу
- Базові SEO метадані, sitemap.xml, robots.txt

**Це не офіційний ресурс МВС.** Не всі записи центрів означають доступність іспиту саме сьогодні.

## Що НЕ реалізовано
- Хмарні облікові записи, відновлення паролів і синхронізація даних між пристроями
- Адміністративна панель, ролі, кабінети інструкторів і рекламодавців
- Серверна API й база даних
- Повні й інтерактивні геометрії всіх офіційних маршрутів
- Офіційний екзаменаційний банк питань — поки тільки авторські навчальні питання
- Платіжні послуги, платні API, Telegram

Не вмикайте публічну реєстрацію до захищеної серверної інфраструктури.

## Розгортання
Гілка: main. Render: static site, publishPath «.», автоматичне розгортання з main.
Після коміту перевірити GitHub Actions «Перевірка сайту», статус Render і реальне завантаження вебсторінок.
Налаштування вебслужби або бази даних потребує окремого безпечного налаштування та міграції; не видаляйте чинний static site.

## Тести
- `python3 tests/validate.py` (потрібен Node.js для перевірки JS)
- `python3 -m http.server 8765` та `node tests/browser.mjs` (потрібен `npm install --no-save playwright@1.57.0`, `npx playwright install chromium`)
- Автоматизовані тести виконуються в GitHub Actions на Ubuntu 24.04.

## Маршрути
Каталог записів: `routes-data.js`. Офіційне джерело: https://hsc.gov.ua/index/poslugi/vidacha-posvidchennya-vodiya/marshruti/
Схеми, перевірені окремо, додано до `routes.html`. Не додавайте схеми без звірки джерела, адреси, дати актуальності та категорії.
ТСЦ №8041 переїхав у вересні 2026 року. Старі схеми з попередньої адреси не позначаються як чинні.

## Безпека та персональні дані
У цій статичній версії паролі не зберігаються, акаунтів немає. Результати тренувань містяться лише в localStorage браузера; будь-який користувач пристрою може їх прочитати, тому не вводьте особисті чи конфіденційні відомості. Експорт у JSON зберігається на пристрої користувача. Для майбутньої авторизації потрібні серверні правила доступу, шифрування трафіку, надійний провайдер і політика обробки даних.
