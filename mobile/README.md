# DRIVE READY UA для iOS і Android

Мобільний тренажер із 24 авторськими навчальними питаннями з сайту, тренуванням на 10 випадкових питань, поясненнями та повторенням помилок. Прогрес зберігається локально. Екзаменаційні маршрути, запис DRIVE TIME і політика конфіденційності відкриваються у браузері. Навчальний банк не є повним екзаменаційним банком ГСЦ МВС.

- Назва для магазину — DRIVE READY UA
- Короткий опис — Тренування ПДР і повторення помилок
- Підтримка — https://drive-ready-ua.onrender.com/
- Конфіденційність сайту — https://drive-ready-ua.onrender.com/privacy.html

## Перевірка та збірка

```sh
npm ci
npx expo install --check
npm run build:check
```

Запускай команди з каталогу `mobile`. CI збирає тестовий APK зі стандартним тестовим підписом. Він підходить для перевірки на Android, а для публікації потрібна окрема збірка з підписом власника.

Перед створенням карток магазинів перевір ідентифікатори з `app.json` у потрібних акаунтах. EAS-проєкт, профілі підпису та дозволи задаються в акаунтах власника. Профіль `production` у `eas.json` призначений для підписаних збірок, а Android submission підготовлено для чернетки на внутрішньому треку. Знімки екрана, огляд вікових обмежень та інформацію про приватність заповнюють для тієї версії, яку відправляють на модерацію. Секрети підпису зберігай у менеджері облікових даних збірки.
