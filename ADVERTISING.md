# Реклама Drive Ready UA — інструкція адміністратора

## Що працює зараз
- Сторінка `ads.html` із форматами, стартовими орієнтовними тарифами, описом переваг і заявкою.
- Заявка перевіряє обов'язкові поля, email, згоду на обробку контактів; створює структурований текст.
- Відвідувач може відкрити заявку у власній поштовій програмі, скопіювати або завантажити TXT.
- **Автоматичного надсилання без налаштованого каналу немає.** Сайт не стверджує, що заявку отримано, доки сервер не підтвердить це.
- Місця реклами на `index.html` і `routes.html`: без схвалених матеріалів показується власна пропозиція співпраці. Сторонні кампанії не вигадуються.
- Регіональний показ у маршрутах працює відповідно до обраної області.

## Як активувати повноцінне отримання заявок
1. Підтвердити **робочу email-адресу**, на яку надходять звернення. У `advertising-config.js` прописати її в `receiverEmail`; це публічний бізнес-контакт (не використовуйте приватний email, якщо не бажаєте його оприлюднювати).
2. До підключення захищеного бекенду відвідувачеві відкриється заповнений лист у його поштовій програмі. Сам факт відкриття вікна не є надсиланням листа.
3. Для безпосереднього надсилання з сайту потрібен серверний `submissionEndpoint` з TLS, захистом від спаму, валідацією й постійним сховищем. Він має отримати POST JSON з `company`, `contact`, `city`, `email`, `phone`, `package`, `message`, зберегти заявку й повернути `{"ok":true,"id":"<ідентифікатор>"}`. Ключі доступу й секрети зберігайте лише на сервері, а не в публічному файлі.
4. Без підключеного endpoint адміністративного списку отриманих заявок на сайті немає. Не використовуйте локальний браузер як серверний реєстр.

## Як публікувати рекламну кампанію
У публічному `advertising-config.js` додайте об'єкт у масив `campaigns` **лише після фактичного погодження, перевірки й отримання оплати за узгодженими умовами**.

```javascript
{
 id: "approved-campaign-001",
 approved: true,
 slot: "routes", // "routes" або "home"
 regions: ["Харківська"], // або ["all"] для всієї України
 title: "Перевірена назва автошколи",
 description: "Узгоджений текст реклами",
 url: "https://verified-advertiser.example/",
 image: "https://verified-advertiser.example/banner.webp", // необов'язково
 startsAt: "2026-12-01T00:00:00+02:00",
 endsAt: "2026-12-31T23:59:59+02:00"
}
```

Після зміни файлу GitHub та успішного розгортання Render реклама з'явиться на сайті. Після `endsAt` вона автоматично перестане відображатися. Відбір відбувається **в браузері**, тому це рішення не підходить для гарантованого обліку рекламних показів та платежів. Жодних підтверджених рекламодавців наразі немає.

## Контроль і статистика
- Рекламні банери явно позначені **«Реклама»**.
- Відкриття зовнішнього сайту використовує `rel="noopener noreferrer sponsored"`.
- Кліки, покази й конверсії **не підраховуються централізовано**, жодна статистика не вигадується.
- Для захищеної адмінпанелі, модерації та реальної статистики потрібні авторизація, серверне сховище й інтеграція з аналітикою з урахуванням приватності.

## Тарифи
500 / 1 500 / 3 000 грн за 30 днів є **орієнтовною початковою пропозицією**, а не офіційно затвердженим прайсом. Формат, вартість і строк погоджуються індивідуально.

## Важливе про захист даних
Не вносьте заявок і персональних контактів рекламодавців до публічного GitHub, URL сторінки, клієнтського конфіга або рекламного каталогу. Для зберігання заявок необхідно обмежити доступ на сервері й запровадити правила зберігання та видалення персональних даних.
